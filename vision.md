# Ratsus — Product Vision

Ratsus is a terminal-native workspace for running and organizing multiple AI coding sessions side-by-side.

## Features

### Session Management
- Create new AI chat sessions with the Nexus agent
- Resume existing sessions from where you left off
- Run multiple sessions side-by-side in the same window
- Open standalone terminal shells alongside agent chats
- Reorder sessions by dragging or keyboard
- Delete sessions with a confirmation dialog

### Workspace Layout
- Split the main area into horizontal or vertical panes
- Resize panes freely with drag handles
- Bundle multiple sessions into one pane
- Toggle focus between the sidebar and main content

### Navigation Sidebar
- Browse sessions grouped by day with separator lines
- Filter sessions by the currently selected project folder
- Switch between Sessions, Plans, and Files modes
- See which sessions are currently running with animated indicators
- Scroll through session lists with visible scrollbars

### Expo (Conversation Cards)
- View all sessions in a folder as a masonry grid of cards
- Filter cards by typing a search query
- Preview recent observations directly on each card
- Navigate cards with keyboard or mouse

### File Viewer
- Browse the project file tree from the sidebar
- Open files in the main pane as read-only previews
- Preview Markdown files with rich rendering
- Preview code files with syntax formatting
- Open multiple file tabs and switch between them

### Terminal
- Run full interactive PTY shells in any pane
- Use mouse and keyboard to select and copy text
- Persist normal terminal sessions across app restarts

### Command Palette
- Open a searchable command list to discover all actions
- Execute commands that don't have dedicated keyboard shortcuts
- Quick-switch workspaces with numbered hotkeys
- Toggle between grouped folder view and flat list view

### Notifications
- See toast notifications when actions complete

### Menu Bar
- Top bar showing the active mode and workspace context
- Right-aligned diagnostics display
